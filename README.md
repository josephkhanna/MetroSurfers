# MetroSurfers

## Description
MetroSurfers is an endless runner game where the player controls Buzz, dodging obstacles throughout campus. This was created as part of a group project for Georgia Tech's CS 6457: Video Game Design course.

## Features
- Move left/right with arrow keys or A/D, jump with space, roll with S.
- Levels increase in difficulty as you progress, including moving obstacles and a chasing Bulldog AI.
- Coin collection gates progression to the next level.
- Pause menu, end menu, and full character animations/sound.

## Technologies Used
- Unity (C#)

## Setup
- Open the project in Unity.
